# 🚀 Resume Shortlist Optimizer

AI-powered Resume Shortlist Optimizer and Recruiter Copilot.

Compare multiple candidates against a Job Description, rank candidates, identify strengths and gaps, generate interview questions, tailor resume bullets, and create recruiter outreach drafts.

## ✨ Features

- 📄 Upload multiple resumes
- 📝 Paste Job Description
- 🤖 AI-powered resume evaluation
- 📊 Candidate ranking
- 🎯 Match score
- 🛠️ Technical skills analysis
- 💼 Experience analysis
- 🎓 Education analysis
- ⚠️ Identify candidate gaps
- 💡 Resume improvement suggestions
- ✨ AI resume bullet tailoring
- 🎙️ Candidate-specific interview questions
- ✉️ Interview invitation drafts
- 📝 Candidate feedback drafts
- 📥 Export shortlist as CSV
- 🖨️ Print / Save PDF report
- 📱 Responsive interface
- 🔐 API key stays in the user's browser

## 🛠️ Technologies

- HTML5
- JavaScript
- Tailwind CSS
- Google Gemini API
- PDF.js

## 🚀 How to Use

1. Open the application.
2. Enter your Google Gemini API key.
3. Paste the Job Description.
4. Upload one or multiple resumes.
5. Click **Run Optimization Analysis**.
6. Review candidate scores, strengths, gaps and recommendations.
7. Use the recruiter toolkit for tailoring, interview questions and outreach drafts.

## 🔑 Gemini API Key

This application requires a Google Gemini API key.

The application asks each user to provide their own API key. The key is stored locally in the user's browser using `localStorage`.

Never share your API key publicly.
